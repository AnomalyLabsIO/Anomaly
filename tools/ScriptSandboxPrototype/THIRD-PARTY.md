# Prototype dependencies

- **MoonSharp 2.0.0**, original BSD-3-Clause-licensed interpreter, restored from the official `MoonSharp` NuGet package. The exact package version and package content hash are in `ScriptSandboxPrototype.csproj` and `packages.lock.json`. No community repackaged interpreter or automatic CLR binder is used. [NuGet package](https://www.nuget.org/packages/MoonSharp/2.0.0), [upstream license](https://github.com/moonsharp-devs/moonsharp/blob/master/LICENSE).
- **Optional source-built MoonSharp 3.0**, supplied through `-MoonSharpAssemblyPath`; no additional NuGet package is involved. The verified local build tested here identifies revision `fbd03678d5c0f731d731d099211c7f4a3a1ae8b7`. Its exact assembly identity and SHA-256 are recorded in [MOONSHARP3.md](MOONSHARP3.md) and each run's report. It remains upstream BSD-3-Clause-licensed; the original DLL is read/copied without modification. [Pinned upstream license](https://github.com/moonsharp-devs/moonsharp/blob/fbd03678d5c0f731d731d099211c7f4a3a1ae8b7/LICENSE).
- **Luau 0.743**, MIT-licensed, official repository commit `9d7748a4f324213a18cb8283fa2a77c330225fa0`. The source is fetched into ignored `obj/luau-src`, verified against the pin and checked for local modifications. The build copies the upstream license and pin beside the generated bridge under ignored `artifacts/native`. [Pinned source/license](https://github.com/luau-lang/luau/blob/9d7748a4f324213a18cb8283fa2a77c330225fa0/LICENSE.txt).

The prototype does not add these dependencies to the Anomaly release or runtime packages. Any later distribution must preserve the relevant license notices and separately review the selected versions and native bridge.
